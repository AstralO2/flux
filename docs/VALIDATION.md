# Validation and development

Tests, fixtures, patch tools and source snapshots are outside the deployable gamemode in the sibling `flux-development` directory at the source checkout root. The source archive includes development instructions and test commands in `flux-development/README.md` and `flux-development/docs/VALIDATION.md`.

The server archive includes runtime files and operator documentation only. Historical machine-specific reports and screenshots are not shipped as current validation evidence. Source/hash checks, headless Lua contracts and native GMod behavior are separate checks; none certifies every third-party addon or an aggregate performance improvement.
